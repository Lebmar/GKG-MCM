# Data provenance and licence

`data/SafeInvest_Synthetic_Data.csv` is an unmodified copy supplied with the
HKUST(GZ) 2026 MCM Senior Group Problem A. The problem describes 180 independent
synthetic scenarios based on selected U.S. series from the Jordà–Schularick–Taylor
Macrohistory Database, Release 6. These are neither historical observations nor
forecasts. The competition data and statement are distributed for noncommercial
use under CC BY-NC-SA 4.0: https://creativecommons.org/licenses/by-nc-sa/4.0/.

Attribution: competition organisers; original database authors Òscar Jordà,
Moritz Schularick and Alan M. Taylor, and the return-series authors cited in
`docs/references.md`. Do not describe these synthetic rows as historical data.
Retain attribution, identify adaptations and preserve the applicable share-alike
licence when redistributing adapted data. Our data copy has not been changed.

`docs/problem_A.pdf` is an unmodified competition statement under that same
stated licence. Independent implementation code has no blanket data licence
applied to it. Analytical transformations and figures identify the synthetic
data source; where they are adaptations, the data's licence continues to apply.
