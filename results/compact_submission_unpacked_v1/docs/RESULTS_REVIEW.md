# 最终缓存结果的独立方法审查

审查范围：只读取已保存的最终汇总表、配对比较、成本敏感性、15 年汇总、客户适配诊断和冻结清单。未读取原始最终收益，未重跑策略，未调整模型。冻结策略为 **S2_review**，冻结组合按股票／债券／票据顺序为 Conservative=(15%,5%,80%)、Balanced=(45%,10%,45%)、Growth=(90%,5%,5%)。

## 1. 主结论应表述为增长与风险的取舍

30 年、60 条最终场景、0.25% 转移成本：

| 指标 | 等权年度再平衡 S0 | 冻结策略 S2_review |
|---|---:|---:|
| 实际 CAGR 中位数 | 3.376% | 3.658% |
| 实际 CAGR 第 10 百分位 | 1.499% | 1.613% |
| 实际最大回撤中位数 | 22.290% | 25.457% |
| 实际最大回撤第 90 百分位 | 39.518% | 43.441% |
| 年度实际收益波动中位数 | 8.242% | 9.626% |
| 发生交易的检查比例，含初始检查 | 100% | 35.5% |
| 初始检查后的交易比例 | 100% | 33.28% |
| 全程名义费用合计的场景均值 | 0.979 单位 | 0.526 单位 |

可以说：冻结策略在这批场景提高了典型增长，减少了交易频率和平均名义费用。中位 CAGR 差异为 +0.282 个百分点，配对场景 bootstrap 95% 区间为 [+0.026,+0.758] 个百分点。

必须同时说：大额损失和普通波动的点估计均高于等权基准。P90 回撤差异为 +3.924 个百分点，95% 区间为 [-2.176,+10.951] 个百分点。预设效用差异为 +0.0232，95% 区间为 [-0.0530,+0.0971]，没有提供稳定的总体效用优势证据。

不应说：全面优于等权、同时提高收益并降低风险、显著提高风险调整表现、可靠保护本金、在所有期限更优。

费用与交易率是实际模拟输出；不应把少交易本身等同于更小的市场风险。0.526 是从初始 100 单位出发的全程名义费用均值，不是年费率。

## 2. 人工保护机制的价值尚未被证明为降低投资损失

在保持固定目标成本门槛策略不变时，比较 S2_review 与 S2_gate：

| 指标差异，审核版减无审核版 | 点估计 | 配对 bootstrap 95% 区间 |
|---|---:|---:|
| 预设平均效用 | +0.00031 | [-0.02555,+0.03041] |
| 中位 CAGR | -0.135 个百分点 | [-0.406,+0.044] |
| P10 CAGR | +0.112 个百分点 | [-0.582,+0.298] |
| P90 最大回撤 | -2.556 个百分点 | [-6.752,+1.698] |

可以说：审核停止交易规则在该样本中降低了 P90 回撤的点估计，并减少了费用，但增长有所降低，主要效用差异接近零，区间包含正负两种结果。

不应说：已证明审核减少大额损失、25% 是最大回撤上限、暂停自动更新相当于避险或变现。

实际有 29/60=48.3% 的路径进入 pending。此后保持原有数量的资产，继续承受市场和通胀风险，所有后续年份继续计分。25% 阈值在损失发生后由下一次年度检查识别，也可能一步跨过；它是服务审核阈值，不是止损保证。永久 pending 是缺乏真实人工处理数据时的明确模拟约定，并未模拟人工能够创造额外收益。

如此高的待审比例也意味着人工服务容量可能成为重要运营限制，不能将此机制描述成几乎无需人工的系统。

## 3. 动态更新呈现风险与增长取舍，不能按最终结果重新选择

冻结前，验证集 S3_review 相对 S2_review 的平均效用差异为 +0.04399，但 95% 区间为 [-0.00634,+0.09625]，未通过预设的正下界标准，因此冻结 S2_review。

最终场景中 S3_review 相对 S2_review：

- 平均效用差异 +0.02180，95% 区间 [-0.02147,+0.06503]，仍未建立稳定效用增益。
- 中位 CAGR 减少 0.260 个百分点，95% 区间 [-0.586,-0.044]。
- P90 最大回撤减少 3.327 个百分点，95% 区间 [-7.543,-0.025]。
- 交易检查比例从 35.5% 增加到 39.22%。

可以说：在预设效用和证据门槛下，没有足够证据启用动态目标。动态更新改变了风险与增长的平衡；在最终样本中，它以降低典型增长换取较低尾部回撤。

不应说：动态更新完全无效、动态策略在所有指标更差、最终平均效用点估计较高所以改推 S3。主要推荐保持冻结决定。以上区间是同一批场景的探索性辅助比较，也未对大量比较做多重性修正。

## 4. 成本敏感性稳健不等于全面稳健

成本率为 0.125%、0.25%、0.5% 时，冻结策略的中位实际 CAGR 分别为 3.664%、3.658%、3.647%，等权为 3.383%、3.376%、3.362%。冻结策略交易率为 35.83%、35.50%、35.06%；审核路径比例均为 48.3%。

因此可以说：在预先指定的成本范围内，增长与少交易的主要定性结果没有改变。仍须说明，其 P90 回撤约为 43.44%，高于等权约 39.50%–39.55%。不能把这项检验延伸为对市场分布改变、结构性危机、人工响应速度等所有假设都稳健。

15 年单独按该期限重新决策的结果也不支持跨期限通用增长优势：S2_review 中位 CAGR 为 3.730%，等权为 3.763%；P90 回撤分别为 33.990% 与 34.104%，差异很小。不要把 30 年策略截断的结果与按 15 年期限运行的结果混为一谈。

## 5. 客户 C 的适配证据未在最终样本保持，必须突出披露

冻结分配为 A→人工、B→Conservative、C→Balanced、D→人工、E→Conservative。此分配不随最终结果更改。

| 冻结自动分配 | 开发数据超限数／场景数 | 最终超限数／场景数 | 说明 |
|---|---:|---:|---|
| B→Conservative，15 年、25% 容忍度 | 2/120=1.7% | 4/60=6.7% | 最终经验比例低于 10%，但 Wilson 95% 上界为 15.9% |
| C→Balanced，30 年、40% 容忍度 | 12/120=10.0% | 10/60=16.7% | 最终经验比例不再满足预设 10% 规则 |
| E→Conservative，6 年、35% 容忍度 | 0/120=0% | 0/60=0% | 最终 Wilson 95% 上界约 6.0%，不能称零风险 |

开发期的客户 C 刚好位于经验门槛边界，其 Wilson 95% 上界已为 16.7%。最终 C 的经验超限率为 16.7%，Wilson 95% 区间约 [9.3%,28.0%]。正确结论是：预设经验条件在最终样本没有保持，适配校准存在明显不确定性；不能据此声称已统计证明总体超限率必然大于 10%。

冻结规则曾将 C 分到 Balanced，不等于最终研究验证了这一分配的安全性。论文可明确说该结果不足以支持对 C 进行无条件自动部署；需要进一步校准或人工确认。这是研究的部署限制，不应伪装成最终测试前就存在的另一套模型分配。

重要实现区别：客户适配诊断中，Balanced 的审核触发值使用该客户的损失容忍度，故 C 为 40%；主运营实验采用通用 25% 服务阈值。C 的最终 P90 回撤为 45.998%，不能拿主表通用审核策略的 43.441% 替代。两者必须分别标注。

对 A 和 D 的人工转介仅意味着提供的三种产品中没有通过所设经验条件的选项，不意味着所有可能的资产组合都无解，更不意味着人工能承诺保本。

α 是披露的服务政策，结果对它有实质依赖：α=.05 时 C 改为 Conservative；α=.20 时 A 可进入 Conservative、B 可进入 Balanced。这个敏感性结果支持对规则透明披露，不支持为了得到熟悉的类别映射而事后调整 α。

## 6. 研究边界与推荐措辞

可以使用以下结论逻辑：

> 我们保留开发阶段冻结的固定目标、成本门槛与人工审核政策。它在最终合成场景中减少交易并提高中位增长，但没有显示全面的风险或效用优势。动态更新表现出增长与回撤的取舍，未达到预设的效用证据标准。人工审核是治理控制，其损失缓解作用尚不确定。客户 C 的适配超限率未在最终场景保持，因此该分配仍需进一步确认。

必须披露：冻结前曾查看全 180 场景的聚合描述统计，因此不应称其为从未接触的 pristine holdout；正式策略拟合、架构选择和调整没有使用最终场景的策略结果。冻结后的最终评估未改变所选策略。

此外，1–120 重估后在同一批数据上输出的 onboarding 是拟合内诊断，不是独立风险校准；60 条独立最终路径只有很少尾部样本，bootstrap 也不能补足未出现的灾难。
